# 방과후소년(放課後少年) 번역 규칙과 용어집

## 형식 규칙 (반드시 지킬 것)
- 입력: trans/src/<파일>.json — 일본어 문자열 배열. 출력: trans/ko/<파일>.json — **같은 길이·같은 순서**의 한국어 문자열 배열 (UTF-8 JSON).
- 원문의 `\n`(역슬래시+n 두 글자, JSON에서는 "\n")은 줄바꿈. 대사는 **최대 2줄**(원문 줄 수가 더 많으면 원문 줄 수까지), **한 줄 최대 18자**(공백·문장부호 포함, 모든 글자는 전각 1칸). 길면 의역해 줄인다. 원문이 1줄이어도 18자를 넘으면 `\n`으로 2줄까지 나눌 수 있다.
- 제어 태그는 그대로 보존하고 길이에 세지 않는다: `!co11` `!co12` `!co13` `!co15` `!co111` (색상), `!wa030` 등(대기), `!sp00` 등, `!na00`. 태그 뒤 `!`가 붙은 형태(`!co11!`)도 원문 그대로 쓴다.
- 이름 변수 `!おさむ!` 등은 아래 표의 한국어 토큰으로 바꾼다 (예: `!co11!おさむ!!co15` → `!co11!오사무!!co15`). 토큰은 이름 4자로 셈. 표에 없는 `!時!` `!分!` `!数!` `!数２!` `!夢!` `!猫!` `!おまいり!` `!あぜ道!` `!カズ!`는 **원문 그대로** 복사.
- 사용 가능 문자: 한글 완성형, 전각 공백 `　`, 전각 문장부호 `！？、。…「」『』（）〜ー・：／＋－×％＆♪☆★○●◎△▲□■→←↑↓` , 전각 숫자 `０-９`, 전각 영문 `Ａ-Ｚａ-ｚ`. **반각(ASCII) 문자·공백 금지**(태그 제외). 띄어쓰기는 전각 공백 `　`. 물결은 `〜`. 말줄임은 `…`.
- 한자·가나를 남기지 않는다. 원문이 전부 기호/영문 등 번역할 필요 없는 경우만 그대로 둔다.
- 외부 번역기 사용 금지. 직접 자연스러운 한국어로 번역. 아이들 말투는 반말, 어른에게는 존댓말. 쇼와 시대 일본 시골 여름방학 분위기 유지(엔·신사 등 일본 배경은 현지화하지 않음).
- 검사: `python -X utf8 tools/check.py <파일>` 로 길이·태그·문자 검사 후 오류 0 확인.
