# 방과후소년(放課後少年) NDS 한글패치 1.0.1

일본판 『放課後少年』(Konami, 2008)의 한국어 패치입니다. 대사·메뉴·설명과 그림 글자를 외부 기계 번역 없이 직접 번역했습니다.

## 파일과 적용
릴리즈의 `Houkago_Shounen_KR.xdelta`를 원본 ROM에 적용합니다. 원본은 일본판 YHGJ이며 SHA-256은 다음과 같습니다.

`09998b7311e3aced413ecc91438fd3072d4326db37dc4ae1f9a4eb597bd7afd1`

```powershell
.\xdelta.exe -d -s "Houkago Shounen (Japan).nds" Houkago_Shounen_KR.xdelta "방과후소년_한국어.nds"
```

결과 ROM SHA-256: `7796f5a4c59cf0d5e8cb6a94c9222c88c273d34a42ac628a229d8238a99b1d37`. 패치는 `-0 -S none`으로 생성했고 복원 결과의 해시 일치를 확인했습니다. ROM은 배포하지 않습니다.

## 번역 범위
- 대사 파일 99개 45,404줄. 고유 문자열 13,858개 전부 번역(미번역 0).
- 스크립트(.ws, x86 16비트 기계어) 내장 문자열 1,748곳. 길어지면 데이터 영역 끝으로 옮기고 포인터를 고쳤습니다.
- ARM9·오버레이 UI 1,133곳: 메뉴, 아이템·카드·친구 메모 설명(`@` 줄바꿈), 저장 안내, `%s년%s반`·`%s월%s일` 서식, 이름표·호칭.
- 이름 입력과 장래희망 입력 키보드를 한글 음절표로 교체(완성형 선택 방식).
- 그림 글자: 타이틀·메뉴 로고, 인트로 문구 5장, 파일 선택·노트 메뉴, 이름 입력 화면, 필드 메뉴와 하위 화면(소지품·컬렉션·앨범·친구 메모·대전 메모·시간 설정), 지도 7장의 손글씨와 하단 안내, 저장 화면, 상점 버튼, 6·7월 달력, 딱지 표시(희·소·중·대·각·승·패·무), 능력치 도움말, 미니게임 도움말.

## 폰트
공식 갈무리 v2.40.4를 사용합니다. 원본 12×12 1bpp 셀에 갈무리11의 11×11 자획을 확대·축소 없이 넣었고, 작은 버튼 안내는 갈무리9를 썼습니다. 한글 1,078자를 JIS 제1수준 한자 칸에 배정했습니다. 로고·지도 손글씨는 나눔스퀘어 네오로 그렸습니다.

## 구조 메모
- 그래픽 WDFF: `byte ^= "WILL CO.,LTD.\0"[i] + 위치`로 암호화(ARM9 0x02006744). 일부 파일은 헤더 없이 평문.
- 3D 모델(HBDF/MDLF) 텍스처는 IMGO/PLTO 블록의 8bpp 색인이며 상하 반전되어 저장.
- ARM9는 내용 변경 후 재압축하면 부팅되지 않아 무압축으로 저장합니다.

## 검증과 한계
- 창 없는 DeSmuME 코어를 내부 입력 API로 조작해 콜드 부팅, 이름 입력, 첫날 대사, 필드 메뉴와 하위 화면, 컬렉션·딱지 화면, 저장 화면을 확인했습니다.
- 지도·상점·달력·미니게임 도움말 등 일부 그림 글자는 그래픽 파일 렌더링으로만 확인했습니다. 전체 플레이·실기 검증은 하지 않았습니다.
- **남은 미번역**: 복권(스크래치 카드) 그림, 우유뚜껑 그림 20종의 상품명, 할인권·과자 포장·엽서 등 작은 아이템 그림 속 글자, 스태프롤 그림.

## 재현
Python 3.13과 `requirements.txt`. 원본 ROM을 상위 폴더에 두고 `tools/extract.py`·`wsextract.py`·`uiextract*.py`로 추출, `trans/`의 원고로 `tools/direct.py`·`chunkfix.py`·`calendar.py`·`gpatch.py`·`bgedit.py`·`sharedbg.py`를 거쳐 `tools/build.py`로 빌드합니다. 스크린샷 기반 패치(`gpatch.py`)는 결과가 `trans/gfx_patches.json`에 기록되어 있어 스냅샷 없이 빌드할 수 있습니다.
